# Register-File
This Register File module serves as a high-performance storage unit designed for Verilog-based processor architectures, featuring a highly parallel interface for simultaneous data access. It manages an array of sixteen registers, with each register's bit-width being configurable via a parameter, though it defaults to 32 bits. The module is engineered to support modern execution pipelines by providing four independent asynchronous read ports, allowing the system to retrieve data from four different registers at any given time based on the provided addresses. For data modification, the unit utilizes a synchronous write mechanism controlled by a single write-enable signal. When the write signal is active, the module performs a dual-write operation, updating two separate registers simultaneously with unique data values during the rising edge of the clock. The design also incorporates an active-low asynchronous reset, which ensures that all sixteen internal registers are cleared to zero upon initialization or system reset to maintain a known state.
